# ubx-sdk-go

Shared Go runtime for ubx-generated per-provider SDK bindings (e.g.
[ubx-sdk-aws](https://github.com/ubiquex/ubx-sdk-aws)). Not meant to be
used directly — generated bindings import `github.com/ubiquex/ubx-sdk-go/runtime`
to serialize resource configs against the provider's real wire attribute
names.

Generated by [ubx](https://github.com/ubiquex/ubiquex) (`ubx sdk gen`).
